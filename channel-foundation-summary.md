## 4. Three Script Templates

### Template A — Sleep/Long-Form Hypnotic (2.5–4 hrs)
Modular, not linear. Built from a long chain of repeating beats, each following:
**(a)** short teaching/reframe → **(b)** metaphor/visualization → **(c)** first-person present-tense affirmation stated twice → **(d)** breath/relaxation transition into the next module.

Roughly 60+ beats total across a full script: opening hook → CTA (comment phrase + like) → relaxation induction → foundational metaphor → reality-filter/belief-shapes-perception explanation → commitment framing (e.g. "90 nights") → evening ritual (3 steps) → blocks of "belief statement" affirmations (5–10 per block, built around a recurring metaphor like a library or a forest of roads) → future-self visualization → morning ritual → a core set of ~10 central belief statements (one of which carries the money-as-energy/manifestation framing) → combined evening invocation → guided nature visualization journey (forest → tree → fruit → river → house → fireplace → return) → dream reassurance passage → closing anchors (confidence, peace) → additional modules as needed (inner-critic dialogue, forgiveness work, inner-child work, trigger reprogramming, gratitude, closing recap).

### Template B — Standard Single-Topic (~30–45 min)
Linear argument, no trance language:
1. Hook — "what if [simple thing] could change your life" + dismiss complex/expensive alternatives
2. Curiosity-gap tease — promise to reveal "the biggest mistake" later (unresolved until near the end)
3. CTA cluster (once, early) — like + subscribe + comment specific phrase
4. Historical/cross-cultural authority section
5. Anticipated-skepticism bridge question
6. Pseudo-anatomical/energetic mechanism explanation
7. Problem framing (modern life / disconnection)
8. Real + pseudo-science blend
9. Named anecdote/case story (skeptic → tries it → breakthrough → closing quote)
10. First-person authority claim ("as a master of X, it is my deep concern...")
11. Deeper pseudo-science layer
12. Payoff — the teased "mistake" revealed, closing the loop from beat 2
13. Step-by-step practical instructions
14. Optional bonus depth layer
15. Expectation-setting ("not a magic wand," gradual timeline)
16. Identity-shift reframe (active self-caretaker vs. passive victim)
17. Opt-out permission ("not for everyone, that's fine")
18. Recap
19. Closing CTA (repeat like/subscribe/comment)
20. Poetic sign-off blessing

### Template C — Manifestation-Ritual (Scarcity/Urgency Format)
Heaviest CTA density of the three, built around a multi-day return loop rather than a single sitting. Distinctive elements:
- Time-bound promise bookend (e.g. "results within 72 hours" opening and closing)
- CTA repeated 8+ times throughout, each phrased slightly differently
- Named composite testimonials with day-by-day specificity
- Invented numerology/codes presented as manifestation numbers
- Blended authority stack (not limited to one figure — e.g. a real Bible citation alongside the branded figure)
- Only minimal genuine citation of the branded figure's real ideas even under their name
- "Reveal the mistake" retention device reused from Template B
- End-screen funnel explicitly directing to the next video

Condensed shape: hook (time-bound promise) → reframe → CTA → "why past attempts failed" → authority stack → numerology → breath induction → the "prayer"/mantra given → visualization → CTA → testimonials → pseudo-neuroscience explanation → CTA → the "mistake" warning → practical advice → the one genuine citation → signs/journaling instruction → CTA → final breath induction → prayer repeated escalating → full visualization → major CTA → return-window instruction → identity reframe close → final CTA cluster → next-video redirect.

## 5. Standing Rules

**Address form:** Always Du-Form (informal), never Sie — confirmed across every reference transcript studied.

**Title formula:** `[FULL ALL-CAPS HOOK] – [FULL ALL-CAPS PROMISE/RESULT CLAUSE] | Name (normal case)`
Example: "MIT 65 BEGINNT DEIN WAHRES LEBEN – DAS WUSSTE ERICH FROMM SCHON VOR JAHRZEHNTEN | Erich Fromm"

**Description:** Repeats the title verbatim — no separate summary.

**Hashtag pool:** `#Psychologie #Tiefenpsychologie #Unterbewusstsein #Selbstfindung #Persönlichkeitsentwicklung #InnereHeilung #Selbstwert #EmotionaleHeilung #Beziehungspsychologie #LiebeUndBeziehungen #InnereStärke #Lebensweisheit` + topic-specific additions, always closing with `#ErichFromm`.

**Playlist:** "Die Philosophie von Erich Fromm"

**Thumbnail rules:**
- Deep navy-black night-sky/starfield gradient background, fine white star speckle, subtle blue-teal nebula tint permitted in a corner — no grid pattern, no golden/amber glow
- Fully desaturated black-and-white portrait using the locked Fromm likeness reference photos (consistent face across every video)
- Pose/expression varies by topic's emotional register: pensive/thoughtful (reflective topics), "shush" finger-to-lips (hidden-knowledge framing), hands clasped as if praying (manifestation topics), alarmed/serious stare (warning topics), contemplative side-profile (general default)
- Thumbnail headline text is always a fresh paraphrase of the hook — never repeats the video title verbatim, not even a shortened excerpt. 2–4 short lines, ALL CAPS, two-tone color split, or white text on a red highlight box for the most emotionally charged phrase
- Small relatable inset icon/diagram tied to the topic, bottom corner, circled or arrow-pointed
- No duration stamp

**Delivery:** Every script as a full package — title, description, hashtags, thumbnail concept, playlist, the script itself — plus PDF and TXT file delivery.
